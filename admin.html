Importar e exportar produtos

Importar ZIP

Envie aqui um backup baixado deste painel (para restaurar os produtos), um ZIP de produtos extras ou um ZIP só com fotos. Se vier em partes, selecione todas.

O Rota Importados é independente do Catálogo Pro: todos os produtos são editados só aqui. Um ZIP exportado pelo Catálogo Pro não altera mais a lista de produtos. Restaurar um backup substitui todos os produtos pelos do backup.

📦 Clique ou arraste o ZIP aqui

Fotos em lote

Envie várias fotos de uma vez. O painel liga cada foto ao produto pelo nome do arquivo: o código (ex.: ADM2-8882.jpg) ou o nome do produto (ex.: Lipoland 15mg.jpg). Para mais de uma foto do mesmo produto, use ADM2-8882 (2).jpg, ADM2-8882_2.jpg ou ADM2-8882-2.jpg.

As que não forem reconhecidas aparecem com sugestões de produtos parecidos: clique na sugestão certa ou digite o código. Se o nome do arquivo não ajudar, use 🤖 Identificar com IA: a IA lê o rótulo da foto (marca, nome, volume) e sugere os produtos do catálogo — você confirma com um clique. Nada é salvo antes de você clicar em Salvar fotos.

🖼️ Clique ou arraste as fotos aqui

Departamentos

Dados da loja

Campos vazios usam o valor padrão do site (arquivo js/config.js). O que for preenchido aqui tem prioridade.

Mostra no Google Analytics as páginas e produtos visitados, de onde vêm os clientes, produtos adicionados ao carrinho e pedidos enviados ao WhatsApp. Para pegar o ID: analytics.google.com → Administrador → Fluxos de dados → seu site → “ID da métrica”. Deixe vazio para desligar.

Pagamento no cartão

O site mostra o preço no Pix e, embaixo, o preço no cartão (Pix + acréscimo) com o valor da parcela. O dólar nunca aparece para o cliente.

Cotação do dólar (interna)

Deixe vazio para usar a cotação exportada pelo Catálogo Pro. Se preencher, vale este valor até você apagá-lo.

Departamentos (categorias)

Crie, renomeie (✏️) e exclua categorias e subcategorias, e defina a ordem. Ao renomear, os produtos (inclusive ocultos) e os links dos banners acompanham o novo nome. A ordem vale para o site (menu de departamentos, barra de navegação, seção “Departamentos” e vitrines da página inicial, filtros do catálogo) e para o catálogo em PDF. Use as setas e clique em Salvar ordem.
